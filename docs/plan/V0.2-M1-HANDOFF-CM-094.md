## Start the stack

Use the dedicated worktree, a supported Node LTS, JDK 17+, and a running local Docker engine.
Do not copy .env files or real OAuth/browser credentials. Free loopback ports
3100 (proxy), 3101 (Next), 8100 (Spring) and 9100 (fake provider).

From frontend:

    npm ci
    npx playwright install chromium
    npm run test:e2e

The runner builds the production frontend with ws://127.0.0.1:8100/ws, launches the
test-classpath backend with isolated containers, waits for readiness and starts the proxy.
E2E_BASE_URL overrides are rejected unless exactly http://127.0.0.1:3100.
Shutdown targets only owned child processes/containers; resource-reaper fallback handles
forced Windows termination. This startup/teardown lifecycle still needs a Docker-enabled
full-stack run before it can be considered verified.
